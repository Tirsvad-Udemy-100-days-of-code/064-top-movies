# Top Movies

Top Movies is Day 64 of Udemy's "100 Days of Code": a Flask website that lists your favourite movies, lets you add them from The Movie Database, rate and review them, delete them, and ranks them by rating. This wiki explains each lecture step and what we gained from it.

## Steps

1. [Step 1: View the movie list](Step-1-View-the-movie-list)
2. [Step 2: Edit rating and review](Step-2-Edit-rating-and-review)
3. [Step 3: Delete movies](Step-3-Delete-movies)
4. [Step 4: Add movies through TMDB](Step-4-Add-movies-through-TMDB)
5. [Step 5: Rank by rating](Step-5-Rank-by-rating)

- [Run the project](Run-the-project)

## How the code is organised

- `domain`: the ranking rule
- `application`: the movie catalogue port
- `infrastructure`: the SQLite database and the TMDB client
- `presentation`: views, forms and templates
